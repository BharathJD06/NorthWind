## 📌 Project Overview
A comprehensive business analysis of the Northwind Traders database — a classic SQL dataset representing a trading company. The project spans SQL querying, Python EDA, and Power BI dashboards to deliver full business intelligence insights across sales, customers, and products.

## 🗂️ Files
| File | Description |
|------|-------------|
| 
orthwind.sql | Full Northwind database SQL script |
| EDA Analysis.ipynb | Python exploratory data analysis notebook |
| North Wind Analysis.pbix | Power BI business intelligence dashboard |
| orderdetails.csv | Order details dataset |
| orderdetails.xlsm | Excel macro-enabled order details |

## 🛠️ Tools & Technologies
- **SQL** — Database querying, joins, aggregations & window functions
- **Python** (Pandas, Matplotlib, Seaborn) — EDA & statistical analysis
- **Power BI** — Business intelligence dashboards & KPI reporting

## 📊 Key Analysis
- Revenue analysis by product, category & region
- Customer segmentation by purchase frequency & value
- Supplier performance & order fulfillment analysis
- Top products and category sales breakdown
- Seasonal order volume & revenue trend analysis
- Employee sales performance comparison

## 💡 Key Insights
- Identified top 10 revenue-generating products and their growth trends
- Customer RFM segmentation revealed high-value repeat buyers
- Seasonal peaks aligned with Q4 order volumes
